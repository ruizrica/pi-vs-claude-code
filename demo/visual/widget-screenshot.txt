TOGGLE WIDGET
═════════════

Press Ctrl+J to toggle between:
- Compact view (above)
- Expanded view (shows all agent outputs)

In expanded view, you can see:
- Each agent's stdout/stderr in real-time
- Token usage per agent
- Agent session IDs
- Full context variables
